Introduction

Traditional antibiotics often fail, especially against multidrug-resistant (MDR) bacteria. Bacteriophages (phages), discovered in 1919, provide a promising therapeutic opportunity but have seen limited use due to a lack of investment in phage standardization and regulatory frameworks. This research seeks to explore phage therapy as a viable alternative or complement to conventional antibiotics, aiming to establish standardized testing methodologies for clinical application. By harnessing artificial intelligence to create personalized combinations of phages, specifically built to patients needs, the chances of resistance developing drops dramatically.

Features

  1. Genomic Data Integration - Merges bacterial (Staphylococcus aureus) and bacteriophage genome sequences into a unified dataset.
  2. Automated Preprocessing- Converts raw genome FASTA files into a machine-learning-compatible format through multiple preprocessing steps.
  3. Host-Phage Interaction Prediction - Uses AI to determine which bacteriophages can effectively target a given S. aureus strain.
  4. Optimized Phage Cocktail Design - Selects the best combination of phages for personalized therapy.
  5. Supervised Machine Learning Model - Employs a tree-based model to predict optimal phage therapy.
  6. Performance Metrics - Evaluates AI predictions using accuracy, precision, recall, F1-score, and AUC.
  7. User Input Handling - Accepts bacterial genome data uploaded by healthcare professionals for personalized recommendations.

Web Interface & Usability

  1. User-Friendly Interface - Provides a streamlined web-based platform for users to upload and analyze data.
  2. Automated Workflow Execution - Runs all preprocessing and AI model steps automatically upon data upload.
  3. Real-Time Processing - Processes genome sequences quickly for fast results.
  4. Error Handling & Validation - Checks input data for formatting issues and missing information.
